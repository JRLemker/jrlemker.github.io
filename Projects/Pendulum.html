Inverted Pendulum Project


The goal of this project is to design and build a self balancing inverted pendulum to begin learning control systems and PID tuning. A few things I hope to get out of the project include learning how to model in Matlab Simulink, control system calculations including forward and inverese kinematics, how to use the model to tune PID, and learn how to code and setup the hardware.

I wanted the design to be a rail setup so that the motor would move the sled in a linear motion to adjust the pendulum. I figured this would simplify the process later on when I am trying to do PID tuning. To do this, I purchased rails with linear bearings. To determine where the pendulum is, I had purchased a rotary encoder that will allow the pendulum to spin freely and return position data. I plan on 3D printing the structure and the sled for the pendulum. All the parts ordered so far are in the table below.
