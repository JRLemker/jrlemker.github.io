Project Overview

I created this application in MATLAB for the Advanced Rocketry Club at the University of North Dakota. The primary goal was to streamline the post-flight analysis process and facilitate knowledge transfer to new team members who would continue this work after graduation.

Originally, I manually performed all post-flight analysis using a combination of Excel, MATLAB scripts, and Python tools. The process was tedious and error-prone, involving constant switching between applications, manual event detection, regression analysis, and data visualization. This app consolidates all operations into a single, user-friendly graphical interface.

The Problem

Post-flight analysis is critical for validating rocket performance and improving future designs. However, the manual process had several pain points:

  • Switching between multiple tools (Excel, MATLAB, Python) interrupted workflow
  • Manual event detection was time-consuming and inconsistent
  • Regression analysis required repetitive code execution
  • Knowledge was siloed in custom scripts that were hard to transfer
  • Each analysis took 2-3 hours of focused work

Key Features

Automatic Event Detection

The app automatically identifies critical flight events including motor ignition, liftoff, apogee, drogue deployment, main parachute deployment, and landing. It uses signal processing algorithms to detect acceleration changes and altitude patterns, eliminating manual data inspection.

Regression Analysis

Performs polynomial regression with user-adjustable degree to fit flight data. The app calculates best-fit curves for altitude vs. time, allowing accurate interpolation and derivative calculations for velocity and acceleration profiles.

Drag Coefficient Calculation

After regression analysis, the app automatically calculates drag coefficients for the launch vehicle, drogue parachute, and main parachute. These values can be fed back into flight simulations for improved accuracy on future rockets.

Manual Override Options

While the app automates most tasks, it provides manual override capabilities for edge cases and anomalies. Users can adjust event detection thresholds, modify regression parameters, and correct erroneous automatic detections.

Analysis Workflow

Step-by-step analysis process

  1. Input rocket parameters: Basic vehicle specifications (mass, dimensions, motor data)
  2. Import flight data: Load altimeter CSV files and simulation results
  3. Automatic analysis: App detects events and performs regression
  4. Review and refine: Verify results and make manual adjustments if needed
  5. Calculate performance: Drag coefficients and performance metrics
  6. Export results: Generate plots and save analysis data

Technical Implementation

The application is built using MATLAB App Designer, which provides a visual development environment for creating professional GUI applications. Key technical components include:

Data Import & Validation

Robust CSV parsing with automatic format detection. The app validates imported data for completeness, checks for corrupted values, and handles different altimeter output formats.

Signal Processing

Uses MATLAB's Signal Processing Toolbox for filtering noisy altimeter data. Applies Savitzky-Golay filtering for smoothing while preserving signal features necessary for event detection.

Curve Fitting

Implements polynomial regression using MATLAB's Curve Fitting Toolbox. Calculates R² values and residuals to assess fit quality. Supports polynomial degrees from 3 to 10.

Lessons Learned

  • User-centered design matters: The app's success came from understanding the actual workflow pain points, not just automating existing steps
  • Balance automation with control: Providing manual override options increased user trust and adoption
  • Documentation is critical: Built-in tooltips and help text made the app accessible to new users
  • Iterative development: Regular feedback from team members led to 3 major version updates
  • Knowledge transfer: Creating this tool was more valuable than just performing the analysis myself
